日语学习中，除了单词和语法，**固定搭配短语**（コロケーション）和**惯用表达**（慣用表現）是让日语更地道的关键。本文整理 N5/N4 阶段常见、考试和日常都高频出现的动词名词短语及常用表达，按类别收录，附中文解释和例句。

## 一、动词 + 名词 固定搭配

这类短语中名词与动词的搭配是固定的，直接翻译往往不自然，需整体记忆。

### 动作类

| 短语 | 意思 | 例句 |
| --- | --- | --- |
| あちらこちらを駆け回る | 东奔西走、四处奔波 | あちらこちらを駆け回ってチケットを探した。（四处奔波找票。） |
| 汗をかく | 出汗 | 走って汗をかいた。（跑得出汗了。） |
| 息を切らす | 气喘吁吁 | 息を切らして教室に飛び込んだ。（气喘吁吁地冲进教室。） |
| 頭を下げる | 低头、鞠躬；认输 | すみませんと頭を下げた。（低头道歉。） |
| 首をかしげる | 歪头；感到不解 | その答えにみんな首をかしげた。（对这个答案大家都很不解。） |
| 目を覚ます | 醒来、睡醒 | 朝六時に目を覚ました。（早上六点醒来。） |
| 耳を傾ける | 倾听 | 先生の話に耳を傾けた。（认真听老师说话。） |
| 口を出す | 插嘴、插话 | 人の話に口を出さないで。（别插嘴。） |
| 声をかける | 打招呼；邀请 | 友だちに声をかけて買い物に行った。（招呼朋友一起去购物。） |
| 手を貸す | 帮忙 | ちょっと手を貸してください。（请帮我一下。） |
| 手を洗う | 洗手；金盆洗手 | 食事の前に手を洗う。（饭前洗手。） |
| 足を止める | 停下脚步 | 看板を見て足を止めた。（看到招牌停下了脚步。） |
| 心を込める | 用心、满怀心意 | 心を込めて手紙を書いた。（用心写了一封信。） |

## 二、惯用句・常用表达（コアイディオム）

这些表达整体理解比逐词翻译更准确，很多与身体部位相关。

| 表达 | 意思 | 例句 |
| --- | --- | --- |
| 顔が広い | 人脉广 | 彼は顔が広いから誰にでも頼める。（他人脉广，谁都能拜托。） |
| 顔を出す | 露面、出场 | パーティーに顔を出した。（去派对露了个面。） |
| 顔に泥を塗る | 丢脸、抹黑 | 家族の顔に泥を塗るようなことはしない。（不做给家族丢脸的事。） |
| 目が高い | 有眼光 | 君は目が高いね。（你真有眼光。） |
| 目を疑う | 难以置信 | その結果に目を疑った。（对那个结果难以置信。） |
| 耳が痛い | 刺耳、听了难受 | その話は耳が痛かった。（那番话听了很难受。） |
| 耳が遠い | 耳背 | 祖母は耳が遠い。（祖母耳朵不好使。） |
| 口が軽い | 嘴快、口风不严 | 彼女は口が軽いから秘密を話せない。（她嘴快，不能说秘密。） |
| 口が堅い | 守口如瓶 | 彼は口が堅いから安心だ。（他嘴严，可以放心。） |

## 七、常用谚语・惯用格言・歇后语

谚语、惯用格言和歇后语能提升表达层次，很多在考试阅读和日常对话中出现。歇后语一类靠**谐音双关**（駄洒落），一类靠**前后语义转折**（类似中文歇后语的「谜面-谜底」结构）。

## 十、易混淆・注意点

1. **かける 的多种搭配**：電話をかける（打电话）、時間がかかる（花时间）、声をかける（招呼）、手をかける（费心思）。注意助词不同，意思不同。
2. **気になる / 気をつける / 気がする** 是 N5/N4 高频考点，注意搭配助词和主语：
   - 気になる（→物/事，做主语）
   - 気をつける（自分が注意する）
   - 気がする（話し手の感覚）
3. **お～する / ご～する（谦逊语）**：お世話になる、ご迷惑をかける、お詫びをする。固定搭配整体记，不要自行替换。
4. **～をする 万能动词**：買い物をする、宿題をする、掃除をする、料理をする。动作性名词 + する 是最常见的动词化方式。
5. **身体部位惯用表达**：顔/目/耳/口/手/足/肩/頭 都有大量惯用语，建议按部位归类记忆，例如「口」→ 口が軽い、口が堅い、口がうまい。
6. **こたえる：答える / 応える** 读音相同，注意**对象和助词**不同：
   - **答える**（对提问/询问，用言语回应）→ 質問に答える、問題に答える、素直に答える
   - **応える**（回应期待/批评/呼声，用行动回应）→ 期待に応える、批判に応える、呼びかけに応える
   - 注意助词都用「に」：「質問に答えてください」（请回答问题）、「批判に応える」（回应批评）、「期待に応えたい」（想回应期待）。
7. **おもいだす：思い出す** 是 N5/N4 高频动词，注意搭配和相近词：
   - **思い出す**（想起、回忆起）→ 名前を思い出す、昔のことを思い出す、ふと思い出す
   - **覚えている**（记得，表示状态）→ 彼の顔を覚えている。（记得他的长相。）
   - 区别：思い出す 是「想起来了」这个**动作**；覚えている 是「记着」这个**状态**。
   - 例句：彼女の名前がなかなか思い出せない。（怎么也想不起她的名字。）
   - 常用表现：思い出して笑う（回想起来发笑）、思い出すと泣きそうになる（一想起来就想哭）。
8. **たつ：経つ**（时间经过、流逝）是 N5/N4 高频词，注意搭配和近义词：
   - **経つ**（时间过去，主语是时间）→ 時間が経つ、月日が経つ、一年が経つ、時が経つのは早い
   - 助词搭配：～が経つ（主语时间），～から…が経つ（从…起过了…）
   - 与 **過ぎる** 区别：経つ 强调时间的**推移/流逝**（常用于主观感叹）；過ぎる 强调**从某一点越过/穿过**（時計が十二時を過ぎる），也可表示时间过了但侧重「超过了某个时刻」。
   - 例句：日本に来てからもう三年が経った。（来日本已经三年了。）/ 時間が経つのは本当に早い。（时间过得真快。）
   - 注意同音字 **立つ**（站立）：立つ場合「駅に立って待つ」（站着等）。
9. **みにつける：身につける** 有两个常见含义，注意区分：
   - **（技能・习惯）掌握、学会** → 技術を身につける（掌握技术）、いい習慣を身につける（养成好习惯）、日本語を身につける（掌握日语）
   - **（穿戴、佩戴）带在身上** → ネックレスを身につける（戴项链）、お守りを身につける（随身带护身符）
   - 例句：早く日本語を身につけたい。（想尽快掌握日语。）/ 大切なものはいつも身につけている。（重要的东西总是随身带着。）
   - 区别：多和「技術・習慣・知識」搭配表「掌握」；和「アクセサリー・財布」等搭配表「随身携带」。

## 十一、学习建议

- 不要死记单词，把**名词 + 动词**作为整体记忆，配合例句理解语感。
- 重点练习助词搭配（を/に/が），很多短语助词是固定的。
- 每天挑 5 个短语造句，输出才能内化。
- 复习时遮住中文，看日语回想意思；再遮住日语，看中文回想日语。
